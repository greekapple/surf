# T-062 handoff (engineering): real-time 3D wave viewer

- `src/features/scale/WaveLive.tsx` (lazy chunk **10.8 kB, 4.9 kB gzip**; three@0.186 was already in the main bundle, no new dependency). `webgl.ts` (cheap capability check, keeps three out of the check), ScaleStage integration, `scale.css` (.live).
- Scene: per-band GLB (COLOR_0 r foam, g thin lip, b distance from crest) with a custom water ShaderMaterial (deep-teal body, Fresnel sky reflection, jade glow where thin and backlit, noisy white foam, animated procedural ripples, sun glitter, fog = horizon colour), a surrounding sea built as four quads framing the mesh footprint (same shader, no seam, 2.6 km), gradient sky dome, surfer placed with `surfer_matrix_colmajor`, ~520 soft-sprite spray particles emitted from the lip and impact-zone vertices (data-driven from COLOR_0). Hero camera is on the beach side (-z; the face looks toward the beach), foam to the left, as in the Cycles a00.
- OrbitControls: full azimuth, polar 10°–88° (2°–80° above water), zoom 2.2–70 m, damping, no pan, touch: one finger orbit, two finger dolly+rotate. The stage exposes `data-az/polar/dist/fps/geoms/textures` on `.live-host` for the tests.
- Poster shows instantly and cross-fades to live (0.5 s; none under reduced motion). Band chips switch the GLB (parsed data cached; GPU copy of the previous wave disposed). Under reduced motion or without WebGL (or after a context loss/load failure) the stage falls back to the existing Spin360 / still poster. Caption unchanged (SPIN_CAPTION + spinCaption). Render loop stops when the stage is off screen or the tab is hidden; DPR capped at 2; everything disposed on unmount.
- Board hook: `LiveBoard {object3d()}` prop + TODO in the component (apply to the surfer's `Board` mesh once the quiver exposes boardOutline). Not wired.
- Tests/checks: tsc, 327 tests, build; journeys 8/8; density; `t062-live.mjs` (canvas, drag azimuth, vertical polar, wheel zoom + bounds, polar limits, band switch loads the GLB, caption, 0 errors, reduced motion has no canvas) ALL PASS at 1440 and 390; `t062-perf.mjs` (18 band switches: geometries 5 → 5, textures 5 → 5, rendering pauses off screen) ALL PASS; `t054-scale.mjs` rewritten for live 3D, 0 fails.
- Shots: `playwright-toolkit/swello/artifacts/t062/{1440,390}-hero.png` (the hour's own band) and `{1440,390}-4-6.png`.

## Honest limits
- Frame rate NOT verified on real GPU hardware: this machine's test browser uses software GL (SwiftShader), where it runs about 13 fps at 390 wide with DPR 2. The ≥ 50 / ≥ 30 fps targets need a check on a real GPU. The shader (7 ripple sines per pixel, 4-octave foam noise) and 520 particles are modest; if it is slow on a phone, cut the ripple loop to 4 and DPR to 1.5.
- Look: closer to the Cycles stills in composition and colour than to their lighting; no true lip curl translucency or refraction, the peel animation was skipped, and the surfer here is the old model (surfer v2 and its regenerated matrices will drop in with no code change; the mirrored matrix is handled by three.js and I do not override face culling).
- `npm run build` now embeds 336 assets (the 8 GLBs and surfer, ~16 MB) in the Worker: the deploy size blocker U-01 gets worse until public/ assets are served separately.
