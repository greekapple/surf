## Surfline (Central Ocean Beach spot page, captured live 2026-10-31 3 pm)

Anatomy, top to bottom: ad banner → global bar (Cams & Forecasts · Maps · Learn · Watch · About, search, Get App, Go Premium) → favourites strip with condition colour + height → spot title + "Nearby spots" + "Add favorite" → tabs (Report & Forecast · Analysis · Charts · Guide) → **multi-cam** (live player + 4 cam thumbnails, single/grid toggle, time-of-clip picker) → **Nearby spots** row (cam still, height, OBSERVED tag) → **Current Surf Conditions** card grid → forecaster text → **Forecast**: 10-day day strip (height range, 3 wind arrows per day, 3-segment AM/mid/PM rating bar, starred "days to watch") → per-day forecaster note → **Cam Matches** (past cam clips whose forecast matched, with % match) → hourly **rating bar** → surf-height bar chart (forecast bars + forecaster observation pins) → wind bars (speed + gust, GFS) → **tide** curve with first light/sunrise/sunset/last light → **swell** components plot → **energy** (nearshore vs offshore kJ, % swell vs windsea) → **consistency** /100 → weather → model run time → **nearby buoys** (each: height, period, direction + individual swell partitions) → spot guide prose → breadcrumb.

| Feature | What it does | Verdict | Our version / data |
|---|---|---|---|
| Surf height as a **range with a human scale** ("3-4 ft+ · waist to shoulder") and an OBSERVED tag when a forecaster saw it | Translates numbers into body heights; separates observed from modelled | **Improve** | We already label estimate vs offshore. Add the body-scale words and tie them to our 3D wave-vs-surfer scale (the differentiator). Observed only from real observations (buoys/cams/user reports), never faked |
| **Rating word + 5-segment bar** (POOR TO FAIR) from a forecaster | One glance answer | **Keep**, make spot-specific | Rating v2 (T-040) per spot; show *why* (swell window ✓, period ✓, wind onshore ✗, tide high ✗) — Surfline never explains its rating |
| **Swell partitions** (2.3 ft 14 s SSW 207°, 2 ft 9 s NW 314°, 1.3 ft 18 s SSW) | Shows the mix of swells | **Keep** | Open-Meteo gives primary/secondary/wind-wave; CDIP/NDBC buoys give spectral partitions. Show which partitions the spot's window actually accepts (new) |

## Magicseaweed (Ocean Beach, archived Jan 2023)

Anatomy: global nav (Forecasts · Webcams · Charts · Features · Photos · Live Data) → spot tabs (Forecast · Historic · Seasonal · Webcam · Tide · Spot Guide · Reports · Photos · Spots · Buoys · Winds) → current report → **hourly table**, 3-hour rows per day: surf range in a solid blue column, **star rating (solid = quality, faded = size potential)**, primary/secondary/tertiary swell each as height + period + rotated arrow, **wind speed with gust, arrow on a green/amber/red cell for offshore/cross/onshore**, weather icon, °F, **probability %** → tide sparkline per day + light times → model run age ("Run Age 14 hrs").

| Feature | Verdict | Our version |
|---|---|---|
| Dense **3-hour table** readable at a glance (everything per row) | **Keep** — the most loved MSW feature | A compact table view next to our graphs, phone-first |
| **Wind cell coloured by shore relation** (green offshore, red onshore) | **Keep** | We compute shore relation already; colour the cell, not just the text |
| **Two-tone stars** (quality vs size potential) | **Improve** | Our rating v2 + a separate "size fit for you" from the user's ability/quiver |
| **Probability / confidence %** per row | **Keep** | Ensemble spread or model agreement → confidence %, labelled |
| **Seasonal and Historic tabs** | **Keep** (later) | Our archive + CDIP hindcast → "how often is it good here in November" |
| **Model run age** shown | **Keep** | We show data time; add run age |
| Classifieds, store, features, promoted content | **Skip** | |

## What SWELLO adds that none of them have

4. **Board Match from your own quiver and ability**, with the board room.
5. Calm, minimal, no ads, no AI imagery on condition surfaces.
