# PacIOOS SWAN for Hawaii (swan-hawaii, 2026-11-11): built, flag OFF

Spec: `docs/specs/DRAFT-nearshore-wiring.md` Phase 1; study: `docs/research/NEARSHORE-MODELS.md` section 2.

**Status: nothing is shown to a user, and the 1,700-line point table is not in the app or Worker bundles** (the code that reads it goes through a registry, `src/ocean/swanTable.ts`, that stays empty until `src/ocean/swanEnable.ts` is imported; checked: 0 hits in `dist` and in an esbuild bundle of the Worker). **To turn SWAN on** set `SWAN_ENABLED = true` AND import `swanEnable` from `src/main.tsx` and `worker/index.mjs`; a test fails if the flag and those two imports disagree. `src/ocean/swanFlag.ts` has `SWAN_ENABLED = false` (a test pins it). With it off, the Worker adds no target, the pipeline makes no request and the headline never takes the SWAN branch.

What exists:
- **Point table** (`src/ocean/swanPointsSourced.ts`, generated by `scripts/nearshore-scan.mjs`): 152 Hawaii spots, **120 get one SWAN cell** (104 distinct cells; Oahu 54, Maui region 32, Kauai 18, Big Island 16), **32 get none, each with its reason** (no wet cell within 1.5 km that is seaward of the pin and 8 to 20 m deep on the 50 m bathymetry, with the depths it did find). Rule: seaward within 60 degrees of the spot's `seaward` bearing, 8 to 20 m deep, nearest. **Every row is "unreviewed"** (provenance says so). The ERDDAP answers it was built from (about 15 MB) are cached outside the repo in `~/Development/swello-data/swan/scan-cache.json`.
- **Reader** (`src/ocean/swan.ts`): ERDDAP JSON for one cell (`shgt`, `pper`, `pdir`), missing values dropped (never filled), metres to feet, times untouched; an hour uses the record at that time or the nearest within 30 minutes, never interpolated.
- **Worker** (`services/forecast-service.mjs`, behind the flag): one target per distinct cell, key `nearshore-swan-<dataset>-<lat>_<lon>-forecast`, TTL 3 h, hot-gated like a MOP point (it matches the shared-group rule `nearshore-*-forecast`). Credit text: "Nearshore model: PacIOOS (UH SOEST, NOAA IOOS), SWAN regional wave model" (`SWAN_CREDIT`; the credit line is not rendered anywhere yet, because nothing renders while the flag is off).
- **Headline** (`swanEstimate` in `src/services/headlineSurf.ts`, behind the flag): the same breaking rule as MOP with the cell's depth and the spot's seaward bearing; label "Surf height from the PacIOOS SWAN nearshore model at the nearest wet cell chosen for this spot, about N m deep (50 m bathymetry), K km from the spot (University of Hawaii; model estimate, unvalidated, uncalibrated for this source; confidence forced low: against the two Hawaii buoys SWAN read about 1.5 ft low; the cell is not reviewed and averages about 500 m, it is not the break; its past hours are model output, not observations); the run covers up to <the model's own last hour>". Confidence is forced low, freshness uses SWAN's own record and any saved copy, and the range text says v2 (never "v1"). `swanEstimate` checks the flag itself. Where the rule cannot present an estimate, the existing v1/offshore path shows as before. Method `swan-v2` is never tuned to a person's reports, never stored as a model/observation pair, never stored as a felt-right prediction, never in the forecast archive (swan hours are skipped), never in similar-session matching. (85 of the 120 spots can produce an estimate for some swell direction; the other 35 have no breaking profile.)
- **Buoy comparison** (`scripts/swan-vs-buoy.mjs`, `docs/forecast/SWAN-VS-BUOY.md`): the SWAN cell containing each buoy against the buoy, 30 days, paired hourly. **Both fail the rule on the first two thirds**: Waimea Bay 106 bias -1.48 ft, average miss 1.71 ft, correlation 0.34; Mokapu Point 098 bias -1.64 ft, miss 1.70 ft, correlation 0.59 (SWAN reads low; the last third is closer at Waimea, -0.04 ft, and still -1.19 ft at Mokapu). **So the flag must stay off.**
- **Capture** (`scripts/swan-capture-local.mjs`): SWAN at every cell plus CDIP 106 and 098 into `~/Development/swello-data/swan/<date>/`, keyless, at most 1 request per second, every 3 h. First capture 2026-11-11 09:57Z: 104 cells (0 failed) and 2 buoy files. It is a manual local loop, not launchd or cron.

Before the flag can go on: a person reads the buoy comparison and the SWAN spot table, the table is reviewed (rows move to owner-reviewed), at least 7 days of captured runs support the spot-level How-right check (the same-source carry ratio from the spec), and the data-honesty review passes. None of those has happened.
