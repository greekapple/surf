## Method
Rounds 1 and 2, reused.
- **Break type.**
  - Pages: the row's own guide pages (every Surfnerd, surf-forecast and Wannasurf URL in its position, facing, facts or `guideMatch`), plus pages found by name: the surf-forecast sitemaps (8,033 `/breaks/` slugs) and the Surfnerd spot sitemap (7,455), and Wannasurf zone indexes (rounds 1–2 indexes plus a new crawl of 53 countries' `/spot/` zones; robots.txt allows `/spot/`).
  - A page found by name counts only when its own page name equals the row name (or its parenthesised alias) or is a near-identical spelling (similarity ≥ 0.85). A page whose name only contains the row name, or the reverse (e.g. "Haggertys" for "Upper Haggertys"), was not used and is listed below.
  - Every page counts only if its own pin is within 6 km of the row's pin.
  - `type` is set only when every counted page that states a type states the same single Beach, Point or Reef (surf-forecast `Beach`/`Point`/`Reef`; Wannasurf Beach-break, Reef-coral, Reef-rocky, Point-break; Surfnerd `Beach`/`Point`/`Reef`). A set type gets `typeSource`.
  - Otherwise the guides' own wording goes into `facts.breakTypeText` and `type` stays null. Pages with no stated type ("Unknown break", "-", "Don't know") are neutral. New source URLs are added to `facts.sources`.
  - Fetching: curl, about one request start every 1.1 s per host. 647 new guide pages and the Wannasurf zone pages were fetched; 728 pages were reused from the 2026-11-09/10 caches.
- **Pins more than 3 km from the coast:** Natural Earth 10 m coastline plus minor islands, over all rows of the nine files and the computed-facing null-type rows elsewhere.
  - Each flagged pin was checked with the OSM API `map` call (bbox 0.02°, UA `SWELLO spot research`, ≥1.2 s apart): the centre box first, then the ring of 8 boxes around it when no coastline was within the box. The distance is to `natural=coastline` way geometry.
  - Rule: within 3 km of OSM coastline → kept and `coastCheck` added (plus a note in `positionSource.text`); otherwise re-source or drop.
- **Duplicates:** every in-scope row against every row in every file: same normalised name within 1 km, or the same guide page URL among the two rows' own guide pages. Same page → one row (the guide-facing row kept, the other row's pages carried into its `facts.sources`); different pages → keep both with distinct guide names; unclear → listed.
