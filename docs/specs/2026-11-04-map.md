# Map: Windy colours, a heatmap that works on phone and while zooming, less AI chrome
Status: **APPROVED** (user, 2026-11-04: "fix that … on phone it doesnt seem like the heatmap even works … the colors are so weird use the same colors as your reference windy … when I zoom out the heatmap goes gray and then restores … the menus look pretty AI … make a spec for this and get to working").

## Context (lead, /explore on :5180, 1440 and 390; shots in the scratchpad `map/`)
- **The heat field** is a canvas (`xfield-field` + `xfield-flow`, `src/map/field.ts`, `SpatialLayer.ts`, colours `src/map/colors.ts`) over a Leaflet Esri basemap. It's masked to the open sea (T-092), with a time scrubber and a legend.
- **Colours:** T-109 changed the ramp to one pale-to-navy hue at 0.5 opacity (site critique, RULES "no rainbow"). The user overrides this: use Windy's wave colours (`docs/design/TEARDOWN-2026-10-31.md` §Windy; reference shots `~/Development/swello-design-references/…/windy/1440-0x-*.png`, `390-0x-*.png`).
- **Zoom:** mid zoom-out the field disappears and the grey basemap tile grid shows (`zooming-1440.png`); the field returns only after the zoom ends. It's redrawn on `moveend`/`zoomend` and isn't transformed with the zoom animation.
- **Phone (390):**
  - the field draws but reads as one flat blue (no visible gradient);
  - the bottom sheet covers about 45% of the screen;
  - the legend is squeezed into a pill;
  - not yet checked on a real phone (DPR 3, touch, iOS Safari canvas size limits).
- **Chrome:** the floating "Spots 45" dropdown, the layer popover, rounded white pill labels on every spot ("Unrated"), and the stacked floating buttons read as generic or AI.

## Problems → target
1. **Colours = Windy's wave-height ramp.**
   - Sample the stops from the Windy reference shots and legend (calm deep blue → blue → cyan → green → yellow → orange → red → magenta for big seas).
   - Same stops in the legend. Opacity tuned so the coastline and basemap still read (about 0.65–0.75), with land fully unpainted.
   - The legend keeps "Offshore wave height · not surf size" (data honesty) and the unit toggle.
   - Record the user's override of RULES "no rainbow" in `docs/design/RULES.md` (maps use the Windy ramp by user decision, 2026-11-04).
2. **Zoom and pan never show grey.**
   - During zoom and pan, the existing field canvas is CSS-transformed with the map animation (Leaflet `zoomanim` / `_animateZoom` pattern); the redraw at the end swaps in without a blank frame.
   - Pan keeps the canvas positioned. Particles pause during the animation and resume.
   - No grey basemap gap at any zoom from 5 to 12.
3. **The phone heatmap works and reads.**
   - Verify on iPhone emulation (390×844 DPR 3, touch) and Android (412×915 DPR 2.6).
   - Cap the canvas size to device limits (draw at DPR ≤ 2, scale up).
   - Make sure the gradient is visible at the default zoom: the colour domain fits the visible values, the legend shows the domain, and there's no single flat colour.
   - The bottom sheet starts as a peek (≤ 25% of the height) and expands on tap or drag; the map gets the rest.
4. **Less AI chrome (Windy-like, function first).**
   - **Layers:** a compact vertical layer list on the right edge (Waves · Swell · Wind · Period), plain icons and text labels, an active state as a filled row. No floating card with a heavy shadow.
   - **Spots:** labels only for the selected spot and the top-rated few at the current zoom. Others are small rating-coloured dots. Hover/tap shows name + surf height + rating. No "Unrated" pill everywhere; the night/dark state is a single quiet mark.
   - **Spot filter:** the search plus the region chips live in one compact top bar on the map (Windy-style), not a floating "Spots 45" dropdown.
   - **Bottom:** the timeline scrubber and the legend sit in one bottom strip, matching Windy's layout at 1440 and 390.
   - Tap targets stay ≥ 44 px (T-109). Dark mode works.

## Constraints
- Data honesty: the legend and labels say offshore wave height, not surf size; "Not covered" stays on enclosed waters; no invented values.
- Performance: 60 fps panning and zooming at 1440 on desktop; ≥ 30 fps on the phone emulation with 4× CPU throttle; no new map library; Leaflet stays.
- Open-Meteo quota: QA runs stay light (a few page loads), no click storms (yesterday's 429).
