# SURF

**A premium surf forecasting and personal surf platform.**

SURF combines ocean forecasting, interactive maps, surf-condition intelligence, and personalized surfboard recommendations into one experience.

## Current Version

**SURF v0.11 — Migration in Progress**

The existing application is being migrated into GitHub with its original development history preserved.

## Features

- **Surf Forecasting** — Swell, wind, tides, surf ratings, and forecast reliability.
- **Interactive Ocean Map** — Geographic forecast layers, wave direction, and time playback.
- **Surf Windows** — Identify promising periods for surfing.
- **Quiver** — Manage surfboards and explore personalized recommendations.
- **Wave Scale** — Interactive educational visualization of breaking-wave heights.
- **Personal Dashboard** — Favorite spots, preferences, and forecast insights.

## Technology

- React
- TypeScript
- Vite
- Leaflet
- JavaScript forecast services
- Cloudflare Workers and R2
